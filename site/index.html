Fee control

Know what should have been collected

Most school software tells you what was collected. That number is only useful if you already trust it. The harder and more valuable question is what the roster says should have arrived — and where the difference went.

Every receipt number is issued in an unbroken sequence. Nothing is ever deleted — a mistake is corrected by a reversal that leaves both entries in the record, with a reason and a name attached.

  • Expected vs collected, class by class, from the real roster
  • Ghost-student check — anyone being billed who never appears in a register
  • Discounts need approval — a clerk proposes, the principal approves, both are recorded
  • Cash drawer settlement — each collector counts their own drawer, and a difference needs a written reason
  • Full audit trail — every change to money, marks and attendance, with who and when

Questions

Straight answers

We're mid-session. Can we switch now?

Yes, and this is the part most systems get wrong. You can import your student list from a spreadsheet and import what each family already owes, so your defaulter list is correct from day one. You do not have to wait for April.

Does it work when the internet goes down?

Attendance does — teachers can open the class list and mark the register with no connection, and it syncs when the internet returns. Fee collection and reports need a connection. We'd rather say that plainly than have you find out on a Monday morning.

Is it a desktop program or a website?

Both, and it's the same system either way. There's a proper Windows application that installs on the office computer with its own icon, and the same thing opens in any browser for teachers and parents. Your data lives in one place, so it doesn't matter which one you use.

Is it in Urdu?

Not yet. The interface is English today. Everything you type in — student names, remarks, fee heads — accepts Urdu and prints correctly. A full Urdu interface is on the list, and if it's the thing standing between you and switching, tell us; it moves the priority.

Can parents see other children's information?

No. A parent account can only reach its own family — that restriction is enforced in the database itself, not just hidden in the app, and we have automated tests that fail the build if it ever stops being true. A parent also cannot see fee totals, staff records, or anything about the school's accounts.

What happens to our data if we stop paying?

Nothing is deleted. Day-to-day entry pauses, but you can still sign in and export everything you have ever entered. We think holding a school's own records hostage is indefensible, so we made sure we can't do it.

How long does setup take?

An afternoon for a small school. You enter your classes and sections, set the fee for each class, and import your student list. Most schools are taking real fee payments the same week.

Fourteen days, no card, no commitment. Put one class in, run a month's challans, and see whether the numbers agree with your register.
